# qfm

Quantum Fock-space machine-learning research: Pauli–Grover and diffusion
Hamiltonians over Krylov subspaces. Implements `dense_pauli_grover_matvec`,
parity/MNIST sweeps, and the star-topology training harnesses documented in
`AGENTS.md` (rank saturation, anti-learning, distributed multi-mode
encoding). See `QFM.tex` for the theory and `qfm_text` for the token-stream
training variant.
