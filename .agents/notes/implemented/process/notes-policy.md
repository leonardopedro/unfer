# Seed note: notes policy

**Category**: process
**Status**: implemented

`/agents/notes/implemented/` holds one note per non-trivial change (category =
architecture | feature | testing | process). Archived notes are frozen (dsh
notes policy): after review, a note is never edited in place — a follow-up goes
in a new note. The PLAN files remain the shared memory; notes are the per-change
decision log.
